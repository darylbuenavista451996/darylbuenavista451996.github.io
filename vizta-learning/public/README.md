# public/

Static files served at the site root.

## Your logo
Put your logo here as **`logo.png`** (this exact name).
It appears in the app header, the certificate, and the browser tab icon.
Square works best (e.g. 512×512). A PNG or JPG named `logo.png` is fine.

To add it from GitHub: open this `public` folder on github.com →
**Add file → Upload files** → drag your logo in → name it `logo.png` → Commit.
The site redeploys automatically.
